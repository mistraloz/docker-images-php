# Tests run by the CI

`run_tests.sh` runs each test file for each variant of `VARIANTS`:

- `TEST_SCOPE=full` (default): every test file on every variant, for every PHP version;
- `TEST_SCOPE=reduced`: each test file only where its result can differ, as listed below. The images of a PHP version
  share their layers (see [Contributing](../docs/contributing.md)): a test of a feature common to the variants is run
  on the *cli* variant only, a test of a feature independent of PHP runs on the latest PHP version only (the latest
  version of `extensions/`). Both architectures run the same tests.

The CI runs the reduced scope, and the full scope when the workflow is started manually with `full_tests`.

A test file missing from this table runs everywhere, as with the full scope.

| Test file                  | Checks                                                           | Variants | PHP versions |
|----------------------------|------------------------------------------------------------------|----------|--------------|
| `onbuild.sh`               | `ONBUILD` instructions (extensions, Composer) of the slim images | cli      | all          |
| `php-blackfire.sh`         | Blackfire extension                                              | cli      | all          |
| `php-extensions.sh`        | Extensions, installed once for the 3 variants                    | cli      | all          |
| `php-ini.sh`               | `php.ini` templates and `PHP_INI_*`                              | cli      | all          |
| `php-security-patches.sh`  | Security fixes of the PHP binary of each SAPI                    | all      | all          |
| `php-xdebug.sh`            | Xdebug extension                                                 | cli      | all          |
| `tool-composer-bin.sh`     | `vendor/bin` in the `PATH` (working directory of the variant)    | all      | latest       |
| `tool-composer-version.sh` | `COMPOSER_VERSION`                                               | cli      | all          |
| `tool-daemon.sh`           | `DAEMON_COMMAND_*` along with the main command of the variant    | all      | latest       |
| `tool-locales.sh`          | `LOCALES`                                                        | cli      | latest       |
| `tool-startup-command.sh`  | `STARTUP_COMMAND_*` (run by PHP)                                 | cli      | all          |
| `tool-supercronic.sh`      | `CRON_*` (crontab generated by PHP)                              | cli      | all          |
| `users-rights.sh`          | User of the commands (working directory of the variant)          | all      | latest       |
| `variant-apache.sh`        | *apache* variant                                                 | apache   | all          |
| `variant-fpm.sh`           | *fpm* variant                                                    | fpm      | all          |
| `variant-node.sh`          | NodeJS images, for each NodeJS version                           | cli      | latest       |
